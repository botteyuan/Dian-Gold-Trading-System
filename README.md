## 一、系统总览（优化后的体系）

```
                      ┌─────────────────────────────────────────────┐
   驱动分析（基本面）  │  货币属性：地缘政治 / 经济增长               │
   Python 每日跑一次  │  投资属性：利率水平 / 资本流动               │ ─┐ gold_signal.ini
                      │  商品属性：金饰需求 / 工业用金 / 央行购金      │  │ (偏置/否决/仓位/凯利)
                      └──────────────────┬──────────────────────────┘  │
                                         │ 偏置 + 日线趋势             │
                                         ▼                            │
   ┌──────────────────────────────────────────────────────────┐ │
   │  B3 多空 Regime 框架（优化核心）                          │ │
   │  基本面偏置 × 日线趋势三态  →  决定方向与仓位偏斜         │ ◄┘
   └──────────────────────────┬───────────────────────────────┘
                              │
                      ┌───────▼──────────────────────────────────┐
   行为分析（技术面）  │  势 = 顾比复合均线：交叉(提醒)→回档(确认)  │ ─→ 市价单
   MT5 EA 每根 H1 判定│  位 = 轴心点混合菲波纳奇：适离            │
                      │  态 = 布林带收口·乖离 + 蜡烛敛散·渐短      │
                      └─────────────────────────────────────────┘
```

**本次优化的核心**：引入 **B3 多空 Regime 框架**。系统不再是单纯的 long‑only——
技术面（五要件）仍是进场的唯一扳机，但**多空方向与仓位比例由"基本面偏置 × 日线趋势"共同决定**。
实盘与回测统一走 B3 口径，做空只在基本面偏空（bias<0）时由 regime 放行，彻底解决了"牛市回测漂亮、熊市实盘失血"的错配。

## 二、交易逻辑

### 进场（势、位、态三要素必须齐全）

**1 小时图 · 五要件**（默认要求满足 3 项，回档为必选项）

| # | 要件 | 工具 | 含义 |
|---|------|------|------|
| ① | **回档**〔必选〕 | 顾比复合均线 6+6 条 EMA | 交叉之后短期组贴近长期组但不穿越 = 单边市确认 |
| ② | **收口〔乖离〕** | Bands(13, 0, 1.618) | 中观敛散节点；做多贴下轨 / 做空贴上轨更佳 |
| ③ | **过度** | 随机震荡 (5,3,3) | 下跌中超买后回落 / 上涨中超卖后回升 |
| ④ | **适离** | 菲波纳奇回调+延伸 ∪ 轴心点 | 价格到位（距离 ≤ 0.35×ATR） |
| ⑤ | **渐短** | 蜡烛敛散 | 小实体 / 长影线 / 十字，且影线渐短 |

五要件齐备 → **确认信号 K 线收盘 → 下一根 K 线开盘进场**。

**4 小时图 · 三形态**（须"出现在布林带的轨道上"）：涨跌吞没 · 启明黄昏（早晨/黄昏之星）· 刺透盖顶（刺透/乌云盖顶）。
> 实证（2023‑2026 牛市回测）：4H 共振对 long‑only 无加成反而损耗，故默认 `InpH4Resonance=false`，保留纯 1H 最优系统。

### 出场（帝娜三定律：必须止损，绝不止盈，用跟进止损）

| 情形 | 触发 | 动作 |
|------|------|------|
| 初始止损 | 有效关键位之外 + 0.30×ATR 缓冲 | 全部止损 |
| 大幅度运动后 | 收盘破布林外轨 | 减仓 50%，止损移成本价 |
| 小幅度运动后 | 收盘反穿布林中轨 | **默认关闭**（反穿中轨会提前把趋势利润洗掉，实盘典型被洗根因） |
| 持仓全程 | 中轨/ATR 跟进止损（浮盈 ≥ 2.5×ATR 后启动） | 剩余仓位让它跑 |
| 反向进场信号 | 出现反向五要件/三形态 | 平仓 |

## 三、B3 多空 Regime 框架（优化核心）

**输入**：`bias` ∈ {+1 多 / 0 中性 / −1 空}（来自 Python 基本面驱动分析） × `d1_trend` ∈ {+1 明显涨 / 0 不明显 / −1 明显跌}（日线 EMA50 + ATR 带宽门槛判定）。

**规则矩阵**（config.yaml `entry.regime_*` 与 EA `DinaRegimeGate` 严格一致）：

| 基本面偏置 | 日线趋势 | 决策 | 多仓系数 | 空仓系数 |
|-----------|---------|------|---------|---------|
| 偏空 (−1) | 明显下跌 | **只开空** | 0 | 1.0 |
| 偏空 (−1) | 不明显 | **双向，空>多** | 0.40 | 1.0 |
| 偏多 (+1) | 明显上涨 | **只开多** | 1.0 | 0 |
| 偏多 (+1) | 不明显 | **双向，多>空** | 1.0 | 0.40 |
| 中性 (0) | 有方向 | **只做多** | 1.0 | 0 |
| 中性 (0) | 不明显 | **站旁边（不开仓）** | 0 | 0 |

- `regime_skew_factor = 0.40`：非优势方向仓位系数，优势方向恒为 1.0。
- **B3 核心**：中性 + 日线无趋势 → 站旁边不开仓，消除"中性平"历史亏损档（全样本 PF<1 的拖累档）。
- 信号文件陈旧（>24h 未更新）→ 保守退回 long‑only，避免"昨天的偏置否决今天的真实信号"。
- 做空总安全锁 `InpAllowShort=true`：仅放行空头总开关，具体多空仍由 regime 矩阵决定。

## 六、日常运行

```bash
# 全量：拉数 → 算指标 → 驱动分析 → 基线回测 → 出报告 → 生成 MT5 信号文件
python run_daily.py

# 把信号写进 MT5 的 Files 目录（EA 每 60 分钟自动读取刷新）
# 将下方路径替换为你本机的 MT5 安装目录：
python run_daily.py --mt5-files "<你的 MT5 安装目录>/MQL5/Files"

# 指定数据源 / 离线 / 用本地 CSV
python run_daily.py --source mt5
python run_daily.py --offline
python run_daily.py --csv data/XAUUSD_H1.csv

# B3 全样本回测（实盘口径，2021-2026，含 2022 熊市）—— 无需启动 MT5
python backtest_full.py
```

产物：
- `output/report.html` —— 每日报告：驱动分析、技术状态、基线回测绩效、要件归因、前瞻表现
- `output/gold_signal.ini` —— 给 EA 的基本面偏置、日线趋势、凯利 f*、关键位、因子明细
- `output/backtest_full.md` / `backtest_full_equity.csv` —— B3 实盘口径回测报告与权益曲线

> **口径说明**：`run_daily.py` 的"主回测"是**纯技术多头基线对照**（`bias=0`，
> 用于隔离技术系统本身表现）；**实盘与 B3 真实口径请看 `backtest_full.py`**。
> 切勿把每日报告里的回测数字当成实盘成绩。

### 图表面板（彩色 GUI）

EA 在图表左上角用 `OBJ_LABEL` 画出彩色面板（涨红跌绿），每 2 秒常驻刷新（休市也显示）：
**信号时间/新鲜度、驱动总分、偏置、日线趋势、Regime 门控与仓位偏斜、否决状态、仓位系数、凯利、技术面五要件快照**。
把 `DinaGuppy` 指标拖到 H1 图可肉眼验证"交叉 → 回档"。

## 八、基本面只做三件事

按书中的定位，驱动分析**不是**进场扳机，只做：

1. **方向偏置** —— 七因子加权总分，`|score| ≥ 2.0` 才产生方向偏置（多/空/中性）
2. **仓位缩放** —— `size_mult` 由偏置强度缩放；与持仓方向一致时放大、相反时缩小
3. **信号文件陈旧检测** —— 超时则 B3 退回 long‑only，避免用过期偏置错杀今日信号

> 注：`veto_enabled` 默认关闭——方向否决的职责已由 B3 regime 矩阵承担
> （偏置翻空时由 regime 直接禁止做多/放行做空），不再单独用"硬否决"开关。

七因子权重（config.yaml）与逻辑层次：

| 层次 | 因子 | 权重 |
|------|------|------|
| 货币属性 | 地缘政治 / 经济增长 / 央行购金 | 2.0 / 1.0 / 1.5 |
| 投资属性 | 利率水平（实际利率，权重最高） / 资本流动 | 2.5 / 1.5 |
| 商品属性 | 金饰需求 / 工业用金 | 0.8 / 0.5 |

无法自动抓取的三项（央行购金、金饰/工业季度数据）在 `config.yaml → fundamental.manual` 手填，范围 −2…+2。

## 十一、风险提示

- 回测未计入滑点、隔夜利息与部分券商的浮动点差，实盘会有衰减。
- `InpAllowTrade=false` 先观察，确认信号与你的主观判断一致后再实盘。
- 帝娜第三定律：**必须止损，不能止盈**。任何"见好就收"的手工干预都会破坏系统期望。
- 历史 bias 局限：仅 INDPRO + DFII10 两宏观因子（沙箱 CBOE VIX 不可达，丢"地缘政治"项），偏空天数偏多；系统定位在"偏置翻空时空头有效"的相对信号，而非绝对预测。
- 回测每笔按 30 点差计（约 0.054R）。交易频率越高，成本占比越大——这是"交易机会"与"盈利"之间的真实权衡。
- B3 仍有判断失误的可能（如偏多环境下 `空|多偏*` 档 PF<1）；regime 是概率性框架，不是圣杯。
